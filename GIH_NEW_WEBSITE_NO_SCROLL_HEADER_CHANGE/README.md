# Green Ink Hub — New Website

A clean, responsive website for Green Ink Hub (GIH), covering architecture, landscape, sustainable solutions and green certifications.

## Pages
- `index.html` — homepage
- `projects.html` — selected work
- `thank-you.html` — form confirmation

## Deploy
Upload the contents of this folder to Netlify, or connect the folder to a Git repository.

Before launch, replace `YOUR-DOMAIN.example` in `robots.txt` and `sitemap.xml` with the final domain.
