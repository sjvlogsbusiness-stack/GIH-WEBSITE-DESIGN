# Green Ink Hub website

Static HTML/CSS/JS website for Green Ink Hub (GIH).

## Files
- index.html — main website
- projects.html — portfolio landing page
- project.html — reusable project detail template
- style.css — design and responsive layout
- script.js — navigation and enquiry form behavior
- assets/gih-logo.png — supplied GIH logo

## Before publishing
1. Replace the Instagram placeholder URL in index.html with GIH's actual Instagram URL.
2. Add project images and details to projects.html / project.html.
3. Add the final domain once purchased.
4. The enquiry form currently opens the visitor's email app using mailto: and sends to greenkinkhub@gmail.com.
5. Generate the final business-card QR code after the domain is live.
